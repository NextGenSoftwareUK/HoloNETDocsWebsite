HoloNET Documentation

HoloNET is the .NET and Unity client for Holochain, plus a family of libraries built on it. Everything here is for HoloNET 4.2+ on Holochain 0.7.0 and 0.7.1.

Examples

Runnable, commented examples of every feature are in examples/: the Client, the ORM, the API, HyperNET, hApp generation (including a WEB5 STAR OAPP) and a web site on Holochain. All of them are run against Holochain 0.7.0 and 0.7.1 on every release. Step-by-step tutorials built on them are at learn.holonet.oasisomniverse.one.

API reference

These pages list every public type and member, generated from the compiled assemblies and their XML docs.

  • HoloNET Client: HoloNETClientAdmin, HoloNETClientAppAgent, HoloNETDNA, requests, responses and event args.
  • HoloNET ORM: HoloNETEntryBase, HoloNETAuditEntryBase, HoloNETCollection, HoloNETObservableCollection.
  • HoloNET API: HoloNETAPI, HoloNETAPIHapp, HoloNETAPIResult.
  • HoloNET HyperNET: HyperNETSession, HyperNETService, options, peers and events.

The main README also has the long-form Client and ORM reference, with every event, method and property described in tables. The CHANGELOG has the full history.

How the pieces fit

code
 Your app / game / service
   │
   ├── HoloNET API        simplest: static key/value + object store, direct messages
   ├── HoloNET ORM        your classes ⇄ your hApp's entries (CRUD, change tracking, collections)
   ├── HoloNET HyperNET   P2P multiplayer: zones, area of interest, reliable messages
   │
   └── HoloNET Client     the conductor connection: admin API, app API, zome calls, signals
          │
          └── Holochain conductor (yours, or the one an .Embedded package bundles)

 WEB5 STAR             generates hApps (Rust zomes + C# on HoloNET) from metadata
 HoloNET Manager       desktop UI over all of the above
 HoloNET HDK           one package: Client + ORM + HyperNET + STAR + HoloOASIS

Regenerating the API reference

The reference pages come from scripts/apigen. Build the libraries with XML docs, then run the generator:

bash
bash scripts/generate-api-docs.sh
